<section>
  <h1>Sneakee – Ecommerce Shoe Store</h1>
  <p>
    Sneakee is a fully functional ecommerce platform designed for selling shoes online.
    The system includes a complete shopping workflow for customers, a powerful admin dashboard
    for managing products, orders, inventory, and users, and a secure payment workflow.
    Built using Django, MySQL, HTML/CSS, and JavaScript.
  </p>

  <h2>Features</h2>

  <h3>🧑‍💻 Customer Features</h3>
  <ul>
    <li>Register, login, and manage profile</li>
    <li>Browse shoes by categories</li>
    <li>View product details</li>
    <li>Add products to cart</li>
    <li>Update cart quantities</li>
    <li>Manage shipping addresses</li>
    <li>Place orders</li>
    <li>View order history and track order status</li>
  </ul>

  <h3>🛠️ Admin Dashboard Features</h3>

  <h4>Product Management</h4>
  <ul>
    <li>Add new products</li>
    <li>Edit and update product details</li>
    <li>Delete products</li>
    <li>Upload multiple product images</li>
  </ul>

  <h4>Inventory Management</h4>
  <ul>
    <li>Track product stock levels</li>
    <li>Update stock quantities</li>
    <li>View low-stock products</li>
    <li>Prevent purchases when product is out of stock</li>
  </ul>

  <h4>Order Management</h4>
  <ul>
    <li>View all customer orders</li>
    <li>Update order status (Pending, Confirmed, Processing, Shipped, Delivered, Cancelled)</li>
    <li>View order details including paid/unpaid status</li>
    <li>Control which action buttons appear based on order status condition</li>
  </ul>

  <h4>User Management</h4>
  <ul>
    <li>Manage customer accounts</li>
    <li>Manage admin/staff accounts</li>
    <li>Activate/Deactivate users</li>
    <li>View user details and order history</li>
  </ul>

  <h4>Category Management</h4>
  <ul>
    <li>Add, edit, and delete product categories</li>
  </ul>

  <h3>Order Workflow</h3>
  <ol>
    <li>Customer adds items to cart</li>
    <li>Customer selects shipping address</li>
    <li>Order is created</li>
    <li>Admin updates order status as it progresses</li>
    <li>Only relevant action buttons are displayed depending on the current order status</li>
  </ol>

  <h3>Payment System</h3>
  <ul>
    <li>Cash on Delivery available</li>
    <li>Payment success or failure handling</li>
    <li>Automatic order status update after payment confirmation</li>
  </ul>

  <h3>Technologies Used</h3>
  <ul>
    <li><strong>Backend:</strong> Django 5</li>
    <li><strong>Frontend:</strong> HTML, CSS, JavaScript</li>
    <li><strong>Database:</strong> MySQL</li>
    <li><strong>Authentication:</strong> Django Auth System</li>
    <li><strong>Template Engine:</strong> Django Templates</li>
    <li><strong>Version Control:</strong> Git &amp; GitHub</li>
  </ul>
</section>
